# MeChatness

Eine Webbasierte Anwendung spezifisch entwickelt für Meetings und Organisationen

## Über das Projekt

Diese Webseite würde für leichtete Kommuniaktion für Organisationen entworfen, um auf Distanz Meetings und bessere Kontrolle über den Prozess der eigenen Organisation zu ermöglichen.
